# NGI People Data Portal

A front-end prototype for NGI's separate People Data and Volunteer Registration portal.

## Prototype features
- Responsive sign-in preview
- Dashboard counters for people, volunteers, active members
- People Data form (existing member records)
- Volunteer Registration form
- Searchable records view
- CSV export for both record types
- Demo records stored in the current browser only

## Demo login
- Username: `ngiadmin`
- Password: `ngi2026-preview`

## Important security and deployment note
This is a front-end demo, not a secure production portal. Demo authentication is client-side and data is stored in local browser storage. Do not use it for real or sensitive personal information. A secure backend, proper authentication/authorization, and shared database/storage still need to be connected before real deployment.

This repository is separate from NGI's main portal.
